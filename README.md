# Pharmacy Management System

A desktop-based Pharmacy Management System developed using Java and MySQL to manage medicines, users, billing, and pharmacy inventory.

## 📌 Overview

The Pharmacy Management System is a database-driven application designed to simplify common pharmacy operations.

The system provides separate functionality for user authentication, medicine management, inventory handling, and billing.

## ✨ Features

- User registration and login
- Admin authentication
- User management
- Add medicines
- Update medicine information
- View available medicines
- Medicine selection
- Billing system
- User verification
- Password recovery
- MySQL database integration

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Java | Application development |
| Java Swing | Desktop GUI |
| MySQL | Database |
| JDBC | Database connectivity |
| Eclipse | Development environment |
